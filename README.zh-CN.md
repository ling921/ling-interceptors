# Ling.Interceptors

`Ling.Interceptors` 是一个 Roslyn 分析器和增量源生成器，基于 C# Interceptors 在编译期替换指定的方法调用点。要求使用 .NET SDK 9.0.200 或更高版本。

## NuGet 包

| 包 | 用途 |
| --- | --- |
| [`Ling.Interceptors`](src/Ling.Interceptors/README.zh-CN.md) | 分析器、源生成器、构建集成和纯编译期拦截 API。 |

## 安装

```shell
dotnet add package Ling.Interceptors
```

包会自动将 `Ling.Interceptors.Generated` 加入 `InterceptorsNamespaces`，消费项目无需手写该属性。

## 使用方式

声明一个静态替换方法。第二个构造参数必须是限定形式的 `nameof(T.Method)`，Scope 为必填参数。

```csharp
using Ling.Interceptors;

internal sealed class Service
{
    internal void Send(string value) => Console.WriteLine($"original:{value}");
}

internal static class Replacements
{
    [Intercept("trace", nameof(Service.Send),
        InterceptionScope.Explicit | InterceptionScope.Compilation)]
    internal static void Send(Service service, string value)
    {
        Console.WriteLine($"trace:{value}");
        service.Send(value); // 直接调用原始实现
    }
}
```

调用点可以显式选择某条规则；也可以由 `Compilation` 覆盖当前项目的普通调用：

```csharp
service./* intercept:trace */Send("one"); // 显式替换
service.Send("two");                      // Compilation 替换
```

## Scope

| Scope | 语义 |
| --- | --- |
| `Explicit` | 允许调用点通过 `/* intercept:id */` 选择此规则。 |
| `Compilation` | 拦截当前 compilation 内匹配的普通方法调用。 |
| `GeneratedCode` | 扩展 `Compilation` 规则，使其包含生成代码；当存在其他源生成器输出时启用两阶段构建。 |
| `None` | 禁用该规则。 |

`GeneratedCode` 必须与 `Compilation` 组合使用。显式规则优先于 compilation 规则。替换方法体及其 lambda/local function 内的调用会被排除，因此替换方法可安全调用原始实现。

## 边界

- 替换方法必须是 internal 或 public 的静态方法，且签名与目标方法兼容。
- 目标可位于当前项目或引用程序集；不能修改已编译 DLL 内部的调用。
- 不支持构造函数、属性、运算符、委托调用和方法组转换。
- v1 仅支持在当前 compilation 中定义规则和替换方法。

## 生成代码与两阶段构建

`Compilation | GeneratedCode` 会识别常规生成文件（`<auto-generated>`、`.g.cs`、`.generated.cs`、`.designer.cs`）与 `GeneratedCodeAttribute`。在命令行 Build、Pack、Publish 中，包会物化其他源生成器输出并执行最终编译，从而拦截同一轮生成代码中的调用。设计时构建只提供预览，不启动嵌套编译。

## 开发

- 构建：`dotnet build Ling.Interceptors.slnx`
- 在 .NET 9 和 .NET 10 测试：`dotnet test Ling.Interceptors.slnx`
- 打包：`dotnet pack src/Ling.Interceptors/Ling.Interceptors.csproj -c Release`
- 基础示例：`dotnet run --project samples/Ling.Interceptors.Sample`
- 包与两阶段示例：`dotnet run --project samples/Ling.Interceptors.PackSample`
